# ВАКУУММАШ — кликабельный макет B2B-сайта

Прототип сайта НПО «Вакууммаш»: каталог, документация, поддержка, проекты, отзывы, пресс-центр, вакансии. Бэкенда нет — данные из JSON (`src/data`, перенесены со старого сайта) через TanStack Query с задержкой 300–500 мс.

## Запуск
```bash
npm install
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit
npm run lint       # ESLint
npm run build
npm run migrate    # перенос данных со старого сайта (см. ниже)
```
Демонстрация состояний: добавьте к любому адресу `?mock=error` (ошибка загрузки) или `?mock=empty` (пустые списки).

## Стек
React + Vite + TypeScript, TanStack Router (файловые роуты, типобезопасные search params на Zod), TanStack Query, Table, Form + Zod, Tailwind CSS v4, Radix UI, lucide-react.

## Структура
```
src/
  config.ts          # PRICE_MODE, контакты компании
  routes/            # файловые роуты (routeTree.gen.ts генерируется автоматически)
  api/               # моковые запросы и query options
  data/              # товары, схемы конфигуратора, проекты, отзывы, документы, FAQ
  configurator/      # движок: resolve / normalize / encodeCfg (без UI)
  components/        # ui, layout, catalog, product, forms, sections, illustrations
  styles/index.css   # дизайн-токены (@theme)
```

## Режим цены
В `src/config.ts`:
```ts
export const PRICE_MODE: PriceMode = 'show' // или 'request'
```
- `show` — цена и итог пересчитываются по опциям и количеству, кнопки «В запрос» и «Скачать спецификацию».
- `request` — вместо цены кнопка «Запросить цену» и модалка с подставленной конфигурацией.

## Состояние в URL
- Каталог: `/catalog/pressure?signal=["HART"]&ex=true&sort=price-asc&page=2`
- Карточка: `/catalog/pressure/dd-200?cfg=type:d,signal:hart&qty=12&tab=specs` — ссылкой можно поделиться.

## Данные и миграция со старого сайта
Реальные данные перенесены с https://vakuummash.ru скриптом `npm run migrate` (`scripts/migrate/`):
- вежливые запросы (пауза 300–500 мс, ≤ 2 параллельных), кэш ответов в `.cache/`, лог в `.cache/migrate.log`; повторный запуск идемпотентен и ничего не дублирует (из кэша — несколько секунд);
- результат — `src/data/*.json` (проекты, отзывы, документы, товары, страницы, контакты, категории), строго типизирован Zod-схемами из `src/data/schema.ts` и проверяется при записи и при загрузке приложения;
- картинки (уменьшены до 1600 px, webp) и файлы лежат в `public/assets/*`, в данных — локальные пути;
- отчёт со сводкой, дублями и всем, что не сопоставилось: `src/data/_migration-report.md`.

Чтобы обновить данные заново, удалите `.cache/` (или нужные файлы в нём) и запустите `npm run migrate`.

### Семейства и конфигуратор
`npm run structure` (`scripts/structure/`) группирует 142 страницы старого сайта в 32 семейства (одна страница товара = одно семейство, модификации — комбинации опций). Опции, правила совместимости (модель → допустимые ВПИ, длины, материалы, взрывозащита) и шаблон артикула выводятся **только из данных**; неподтверждённые значения помечены и перечислены в `src/data/_structure-report.md`, там же счётчик «воспроизведено X из Y» и список решений, нужных от заказчика. Результат: `src/data/families.json`, `family-content.json` (описание по блокам: применение, особенности, таблицы характеристик, схема заказа; исходный текст в `legacyText`), `src/data/configs/<семейство>.json`.

Цены на старом сайте не опубликованы, поэтому везде «Цена по запросу» (`PRICE_MODE = 'show'` показывает цену, только если она есть в данных). У одностраничных семейств (услуги, нагреватель, бобышки…) конфигуратора нет.

## Заглушки (на старом сайте таких данных нет)
Лежат в `src/data/mocks.ts`; перед публикацией заменить или удалить:
- FAQ и «Вопросы к специалистам» (обезличенные карточки отдела продаж);
- видеоинструкции в «Поддержке»;
- карта на странице контактов, формы (данные никуда не отправляются), переключатель RU/EN.

Цифры на главной (позиции, проекты, отзывы, документы) считаются по реальным данным. «Популярные товары» — по два первых товара датчиков давления и температуры.

## Дизайн-токены
Определены в `src/styles/index.css` (`@theme`): `brand-*` (синий), `accent-*` (оранжевый, только акценты), `ink-*` (серо-голубые нейтральные), шрифты Inter и IBM Plex Mono.
